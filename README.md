# 🐍 Python Learning Journey

My personal notes and practice code while learning Python — from the basics all the way to OOP, regex, SQLite, Flask, and an intro to NumPy/Pandas/Matplotlib for AI & Data Science.

Each folder is a topic, numbered in the order I studied it. Every file is a small, self-contained script with comments explaining the concept and short examples/output.
